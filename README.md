# Gilded Pages

Build a Premium Luxury Wedding Invitation Website

ROLE

Act as a senior creative director, award-winning web designer, UX/UI designer, and frontend engineer specializing in premium editorial websites and luxury wedding experiences.

I want you to build a complete, production-quality, highly polished luxury digital wedding invitation website.

The uploaded reference video in this conversation is the primary visual and interaction reference.

Do not create a generic wedding website.

The goal is to recreate the feeling, composition, elegance, pacing, typography, whitespace, transitions, and premium editorial aesthetic of the reference while creating an original implementation.

The final result should feel like a luxury printed wedding invitation transformed into an immersive digital experience.
